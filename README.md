# Webcake Landing A–Z Skill

Reusable Codex skill for product analysis, Vietnamese sales copy, responsive landing pages, native Webcake checkout, Pancake POS, Meta Pixel/CAPI and evidence-based verification.

## Install in Codex

Ask Codex: "Use skill-installer to install webcake-landing-complete from this GitHub repository: <repository-url>."

Then open a new Codex session if needed for skill discovery.

## Use

"Use $webcake-landing-complete to complete a landing for this product: [product details, images, prices and offer]."

Routine setup decisions are handled by the skill. Account access and essential missing business facts may still be required. This repository contains instructions, not account credentials, deployed sites or a standalone landing generator.

The skill is in webcake-landing-complete/SKILL.md. The historical baseline has redacted account identifiers and the original local workspace path.
